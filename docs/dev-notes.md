## 설계

같은 매물을 **지도**와 **목록** 두 화면으로 봅니다. 위치를 찍은 매물만 지도에 뜨고, 모든 매물은 목록에 뜹니다.

- 지도: 위치를 찍은 매물만 핀. 핀 색 = 상태. 핀 → 요약 카드 → 상세
- 목록: 전체 매물. 날짜순(임장일, 없으면 등록일)과 지역별(시·구로 묶음)을 바꿔 봄
- 위치 찍기: 장소·주소 검색 / 지도에서 탭 / 현재 위치(현장에서)

상태는 **관심(임장 전) → 임장함 → 계약 또는 포기**입니다. 포기는 사유를 적어야 저장됩니다.

매물 항목 (예시는 매물 사이트 화면 형식을 따른 가상의 값):

| 묶음 | 항목 | 단위·형식 | 예시 |
| --- | --- | --- | --- |
| 기본 | 매물명 | 글자 | ○○대학병원 문전약국 임대 |
| 기본 | 지역 | 시·구 | ○○시 ○○구 |
| 기본 | 위치 | 지도 핀(선택) + 위치 메모 | 임장 후 핀 |
| 거래 | 거래유형 | 임대 / 양도 등 | 임대 |
| 거래 | 보증금 | 만원 | 5,000 |
| 거래 | 월세 | 만원 | 300 |
| 거래 | 관리비 | 만원 | 15 |
| 거래 | 권리금 | 만원 | 15,000 (1억 5천) |
| 입지 | 상권 | 글자 | 종합병원 |

저장 구조: Firestore `users/{내 계정}/listings/{매물}`에 매물 하나당 문서 하나. 보안 규칙으로 로그인한 본인 계정만 읽고 쓰게 잠급니다.

디자인 기준 (토스·카카오T 참고: [토스 제품 원칙](https://toss.im/tossfeed/article/importance-simplicity), [토스 UX 라이팅](https://toss.im/tossfeed/article/uxwriter-interview)):

- 화면마다 할 일 하나, 주요 버튼 하나를 크게
- 안내·경고는 실수했을 때만, 원인과 다시 하기를 버튼 근처에
- 선·그림자 대신 여백과 연회색 면, 그림자는 지도 위에 뜬 것만
- 글씨 3단계(굵은 제목 / 본문 / 회색 보조), 금액은 크고 굵게
- 강조색은 주황 #F96949 하나, 최소한으로만 사용. 큰 버튼은 주황 테두리만, 작은 버튼은 채워도 됨. 글자 버튼·아이콘은 무채색. 상태 색은 순하게 하고 핀과 작은 표시에만
- 말투는 짧은 해요체, 버튼 문구는 '\~하기'
- 누르는 곳은 44px 이상, 입력 글씨는 16px 이상 (아이폰 확대 방지)
- 글꼴은 Pretendard, 한국어 줄바꿈은 띄어쓰기 기준
- 시트는 지도를 덮지 않게 아래에 둠 (카카오 지도 로고 보호, 지도 API 일반 관행)

### C. Firebase (새 프로젝트) — 보류

2026-11-05 결정으로 보류했습니다. 클라우드 동기화가 필요해지면 아래 순서로 준비하고, 폰의 백업 파일로 데이터를 옮깁니다.


- [ ] console.firebase.google.com → **프로젝트 만들기**: 이름 `imjang-map`. Google 애널리틱스는 꺼도 됩니다
- [ ] 프로젝트 홈에서 **웹 앱 추가(\</> 아이콘)**: 닉네임 `imjang-web`, 'Firebase 호스팅 설정'은 체크하지 않음 → **앱 등록** → 화면의 `const firebaseConfig = { … }` 블록 전체 복사
- [ ] 왼쪽 **빌드 → Firestore Database → 데이터베이스 만들기**: 버전(Edition)을 물으면 **Standard**, 위치는 **asia-northeast3 (서울)**, 규칙은 **프로덕션 모드**. 위치는 나중에 바꿀 수 없어요
- [ ] Firestore의 **규칙** 탭에 아래 내용을 통째로 붙여넣고 **게시**
- [ ] 왼쪽 **빌드 → Authentication → 시작하기 → 로그인 방법 → 이메일/비밀번호 → 사용 설정 → 저장**
- [ ] **Users(사용자) → 사용자 추가**: 앱에서 쓸 이메일·비밀번호 입력
- [ ] (메뉴가 있으면) Authentication **설정 → 사용자 작업**에서 가입(생성) 허용 끄기. 모르는 사람이 계정을 만들지 못하게 막습니다

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}
```

이 규칙은 로그인한 본인 계정 폴더만 읽고 쓰게 하고, 나머지는 모두 막습니다.
